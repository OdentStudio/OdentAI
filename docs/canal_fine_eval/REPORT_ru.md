# Нижнечелюстной канал: второй проход на мелкой сетке (0,25 мм)

2026-10-05/06. Ветка `canal-enhance` (локально, не запушена).

## Проблема

КТ Колковой (`C:\Dental\Dmitry\Guides\14 10 26 Колкова ...\Колкова ТВ.dcm`, 0,15 мм, поле 100 мм):
левый канал находился двумя обрывками, 105 мм³, без передней половины хода. Правый в порядке
(457 мм³, 49 мм). Нынешний второй проход (подгонка яркостей) находил ещё меньше и откатывался.

Отдельно: обрезка по челюсти с запасом 20 вокселей (как в нынешнем втором проходе) сама по себе
теряет 2/3 левого канала — сети нужен контекст. Запаса 15 мм хватает (30 мм не лучше).

## Проверка на 22 КТ (Guides + Kacper)

Мелкая сетка считалась **принудительно на каждом скане**, чтобы увидеть, не портит ли она здоровые.
Полные цифры: `logs/cases.log`, `logs/results.tsv`.

**Сработал триггер (канал «сломан») — 5 сканов:**

| скан | первый проход R / L, мм³ | мелкая сетка R / L | что будет в продакшене |
|---|---|---|---|
| Колкова | 457 / **105** (2 куска) | 469 / **305** (весь ход) | **исправлено** |
| Титов | 0 / 0 | 0 / 0 | нижней челюсти в кадре нет (кусок 8×12×10 мм) — норма |
| Bator post-op | 0 / 0 | 0 / 0 | канала в кадре нет — норма |
| Łukaszewski post-op | 0 / 409 | 0 / 377 | одна сторона вне кадра; мелкая меньше → откат к первому |
| Łużna post-op | 132 / 166 | 115 / 157 | маленькое поле; мелкая меньше → откат к первому |

**Здоровые — 17 сканов** (в продакшене второй проход для них не запускается вообще):
мелкая сетка даёт тот же ход (длина ±0,6 мм), объём −7…+4%. Единственное отличие:
Zyga и Zyga post-op — правый канал 2 куска вместо 1. То есть **включать мелкую сетку всем
подряд не надо**, только по триггеру — так и задумано.

**Время прохода на мелкой сетке (запас 15 мм):** 25–75 с, кроме Bator — 324 с. Причина: рамка
строится по всем вокселям метки челюсти, включая мелкие ложные пятна, и раздулась до
123×171×147 мм (197 млн вокселей). Надо строить рамку по крупнейшему куску челюсти и ограничить размер.

## Рекомендация

**Да, в продакшен — вместо нынешнего второго прохода (match).** На 22 сканах он ни разу не помог,
а на Колковой вредил; мелкая сетка исправила единственный реально сломанный канал и ничего не ухудшила
(откат при меньшем объёме срабатывает правильно).

Перед релизом:

1. Рамка по крупнейшему куску челюсти (`_mesh.drop_small` / самая большая компонента), запас 15 мм,
   и предел размера (например, ≤ 120 млн вокселей; больше — проход пропускаем с сообщением в логе).
2. Правило приёмки: сейчас «больше общий объём». Лучше: слабая сторона выросла, сильная потеряла
   не больше ~15%. На этих 22 сканах результат тот же, но правило честнее.
3. Сделать `fine` значением по умолчанию для `canal_refine_mode`; `match` и AHE (`--canal-enhance`)
   оставить флагами или убрать — по данным они бесполезны.
4. Поверхность канала после второго прохода строится из маски на сетке 0,3 мм (ступеньки). Можно
   строить её прямо из сетки 0,25 мм — глаже.
5. Пересобрать exe, `scripts/smoke_test.py`, прогнать Колкову через аддон.
6. Dice по размеченным данным (`scripts/eval_vs_manual.py`, labelsTs) — на этой машине разметки нет;
   желательно прогнать на Linux-машине, где она есть.
